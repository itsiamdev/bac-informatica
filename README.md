## Rularea website-ului

Din directorul rădăcină al proiectului, rulează:

```bash
cd website
npm run dev
```

Deschide adresa locală afișată în terminal (de obicei http://localhost:5173). Pentru a opri serverul, apasă `Ctrl+C`.
