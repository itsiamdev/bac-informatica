# Structura proiectului

- `mate-info/` — materiale pentru profilul matematică-informatică;
- `stiinte-ale-naturii/` — materiale pentru profilul Științe ale naturii;
- `website/` — aplicația web realizată cu React, TypeScript și Vite;
- `resources/` — bibliografie, linkuri și formule comune;
- `docs/` — documentația și planificarea proiectului.

Materialele specifice unui profil se păstrează în directorul acelui profil; resursele comune se păstrează în `resources/`.
