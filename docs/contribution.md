# Ghid de contribuție

Contribuțiile sunt binevenite. Pentru a păstra materialele ușor de folosit:

- organizează fiecare material în secțiunea și tema potrivită;
- explică algoritmul și precizează formatul datelor de intrare și ieșire;
- verifică soluțiile cu exemple și respectă programa profilului;
- folosește denumiri descriptive și păstrează formatul Markdown existent.
